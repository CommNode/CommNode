# Contributing to CommNode

Thank you for considering contributing to CommNode! This project is built with ❤️ by the community.

## Ways to Contribute

- **Report bugs** - Open an issue with a clear title and description
- **Fix bugs** - Submit pull requests with bug fixes
- **Implement features** - New features are welcome, please open an issue first to discuss
- **Improve documentation** - Help update or translate the README
- **Test the project** - Run existing tests and report results

## Development Process

1. **Fork the repository** and create a branch from `main`
2. **Create a new branch** for your feature/fix: `git checkout -b feature/amazing-feature`
3. **Write code** following the existing style and conventions
4. **Test your changes** thoroughly
5. **Commit with clear messages** referencing related issues
6. **Push to your fork** and open a Pull Request

## Bug Fix Process

- Use the issue tracker to report bugs
- Include steps to reproduce the problem
- Mention your environment (OS, Python version)
- Submit a pull request with a fix

## Feature Request Process

- Open an issue describing the proposed feature
- Discuss the approach with maintainers
- Wait for approval before implementing
- Submit the feature as a pull request

## Coding Standards

- Follow Python PEP 8 style guidelines
- Use type hints where appropriate
- Document public functions and classes
- Keep changes minimal and focused
- Ensure backward compatibility when possible

## Pull Request Guidelines

- Fill the PR template completely
- Ensure all tests pass
- Lint your code before submitting
- Link any related issues
- Be responsive to feedback

## Recognition

Contributors will be recognized in the project's README and release notes.

## Questions?

Open an issue or contact the maintainers for any questions about contributing.
